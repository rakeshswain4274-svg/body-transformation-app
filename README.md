# Transform Pro v2.0

A private, offline-first Body Transformation and Fitness PWA designed for iPhone.

## Main capabilities

- Personalized 12-week beginner program for home workouts
- Two 5 kg dumbbell and bodyweight exercise plan
- Workout stopwatch, set completion and rest timer
- Daily readiness, sleep, steps and hydration check-in
- Meal, protein, vegetable and fruit execution tracking
- Weight, waist, BMI screening and habit trend charts
- Weekly summaries, streaks and achievements
- Light, dark and system appearance modes
- IndexedDB local storage with automatic migration from version 1
- JSON backup/restore and CSV export
- Installable and usable offline after the first successful load

## Privacy

GitHub Pages hosts only the static app files. Personal entries remain in the browser storage on the user's device unless a backup file is manually exported and shared.

## Deployment

Publish all deployment files at the root of the GitHub Pages repository. The required entry file is `index.html`.
